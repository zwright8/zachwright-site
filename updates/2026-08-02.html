Swarm Daily: Agent Stacks Need a Migration Calendar

API sunsets, model shutdowns, runtime breaks, and replacement paths turn agent dependencies into a dated operating queue.

The Big Thing

Agent infrastructure is becoming deadline-driven.

OpenAI's current Assistants API FAQ says the API will be removed in August 2026 and points developers toward the Responses API and Agents SDK. Google's Gemini deprecation table publishes shutdown dates and replacement model IDs, including the August 17 retirement of Imagen models. GitHub's Copilot Billing Preview app retires tomorrow, August 3, in favor of billing settings, usage reports, budgets, and the billing API.

These are not ordinary dependency bumps. Each one changes a contract: API objects, model behavior, runtime requirements, packaging, or the place operators pull spend data. The move is to keep a dated compatibility ledger with an owner, replacement, test path, and last safe migration window for every agent dependency.

  • OpenAI's current Assistants API FAQ and migration direction: https://help.openai.com/en/articles/8550641-assistants-api
  • Google's Gemini model shutdown dates and replacement IDs: https://ai.google.dev/gemini-api/docs/deprecations
  • Imagen's August 17 shutdown and Nano Banana migration path: https://ai.google.dev/gemini-api/docs/image-generation
  • GitHub's August 3 Copilot Billing Preview retirement: https://github.blog/changelog/2026-07-07-copilot-billing-preview-app-will-be-retired-on-august-3/

Code & Tools

  1. AI SDK 7 migration - Node.js 22 and ESM are requirements; use the codemod, then review runtime and semantic changes manually. AI SDK 7
  2. Migration skill - start with npx skills add vercel/ai --skill migrate-ai-sdk-v6-to-v7, then inspect the diff for telemetry, tool context, approvals, and multi-step result changes. Vercel migration path
  3. Harness portability - Vercel's experimental HarnessAgent gives Claude Code, Codex, and Pi a common adapter surface. HarnessAgent
  4. Compatibility window - Cloudflare's Agents packages support AI SDK 6 and 7, allowing an incremental upgrade instead of a flag day. Cloudflare Changelog
  5. Replacement lookup - use Google's deprecation table to map every model ID to a supported replacement before the shutdown date. Gemini deprecations

Tech Impact

  • Deprecation is now queue work. Track it like an incident: owner, deadline, blast radius, migration branch, contract tests, and rollback.
  • Compatibility means semantics, not imports. A replacement can change tool schemas, model outputs, billing exports, or durable objects while keeping the headline capability.
  • Agents are good at the first draft of a migration. The human review surface should be the semantic diff across runtime, package format, model behavior, and operator workflows.
