Swarm Daily: Agents Need Delivery Contracts

Vercel Chat SDK Dial, Photon, Connect, and eve channels, GitHub Copilot app GA, Workers Cache, and GitHub secret metadata move agents from demos into channel-bound production endpoints.

The Big Thing

The useful shift is from "the agent has a chat UI" to "the agent has delivery contracts." Once an agent sends texts, iMessages, Slack replies, support emails, and app messages, the product contract includes credentials, webhooks, thread identity, media, transcripts, latency, and escalation paths.

Vercel shipped a tight cluster around Chat SDK channels: Dial support gives bots SMS, MMS, iMessage, bidirectional media, inbound voice-call transcripts, HMAC-verified webhooks, and stable per-conversation threading. Photon support adds native iMessage group chats, media, and tapbacks. Vercel Connect lets Chat SDK bots use managed Slack, GitHub, and Linear connector credentials instead of app-owned tokens and signing secrets. The new eve Chat SDK channel then turns those adapters into agent surfaces, so one eve agent can run through Facebook Messenger, WhatsApp, Resend, Liveblocks, or any other adapter. This is not just more integrations. It is the channel layer becoming production infrastructure.

  • Chat SDK Dial support turns phone-number bots into adapter-backed SMS, MMS, iMessage, media, transcript, webhook, and thread workflows. https://vercel.com/changelog/chat-sdk-adds-dial-support
  • Vercel Connect gives Chat SDK bots managed connector credentials for Slack, GitHub, and Linear without storing tokens or signing secrets in the app. https://vercel.com/changelog/chat-sdk-vercel-connect
  • eve can now mount any Chat SDK adapter as an agent channel with normal handler code and channel-specific webhook routes. https://vercel.com/changelog/eve-chat-sdk-channel

Code & Tools

  1. Chat SDK Dial adapter - build phone-number bots with SMS, MMS, iMessage, media, voice-call transcripts, signed webhooks, and stable conversation threads. https://vercel.com/changelog/chat-sdk-adds-dial-support
  2. Vercel Connect for Chat SDK - spread connector-backed Slack, GitHub, and Linear configs into adapter factories instead of copying bot credentials into runtime secrets. https://vercel.com/changelog/chat-sdk-vercel-connect
  3. Chat SDK Photon adapter - ship iMessage bots that support direct chats, group chats, media, and tapbacks through Spectrum Cloud, self-hosting, or a Mac. https://vercel.com/changelog/chat-sdk-adds-photon-support
  4. eve Chat SDK channel - expose the same agent through Facebook Messenger, WhatsApp, Resend, Liveblocks, or any Chat SDK adapter while keeping normal Chat SDK handler code. https://vercel.com/changelog/eve-chat-sdk-channel
  5. GitHub Copilot app GA - run desktop agent sessions across Copilot plans, or bring your own model key when a Copilot subscription is not the right control surface. https://github.blog/changelog/2026-07-07-github-copilot-app-available-to-all/
  6. Cloudflare Workers Cache - put a tiered HTTP cache in front of Worker-origin channel endpoints with Wrangler config, Cache-Control, tags, and scoped purges. https://blog.cloudflare.com/workers-cache/

Tech Impact

  • Adapters become product contracts. Thread IDs, webhook signatures, media behavior, transcript handling, retries, and delivery failures need tests, not just docs.
  • Credential custody moves up a layer. Connector UIDs are easier to rotate, audit, and scope than copied bot tokens spread across app environments.
  • Native channels raise the support bar. A bad agent reply is now a wrong-thread text, stale iMessage, missed support email, or broken escalation path.
  • Multi-channel parity is an ops problem. Opt-outs, retention, audit logs, human handoff, and rate limits need the same semantics across every surface.
  • Latency has user-visible blast radius. Cached Worker endpoints can make channel bots cheaper and faster, but cache keys must respect tenant and user boundaries.
