Swarm Daily: Prompts Need a Build Pipeline

Google's prompt transpilation, Conductor's portable specs, Copilot review head-branch instructions, ADK Go graphs, Vercel skill plugins, and Slack agent UX make agent behavior buildable.

The Big Thing

The useful shift is from treating prompts as prose to treating the instruction layer as source code: modularize it, resolve dependencies, validate it in CI, and ship a reviewable rendered artifact.

Google's latest agent guidance calls out the production failure mode directly: monolithic prompts hide blast radius, drift through copy-paste, and defer missing variables or imports until runtime. Its proposed prompt transpiler turns fragments into deterministic outputs that can be tested, audited, diffed, and drift-checked before the model sees them.

Conductor makes the same move at the project level. Specs and plans remain persistent, version-controlled Markdown, while the interaction becomes conversational and portable across agent tools. The interface can change; the repository-backed contract does not.

  • Google's prompt-transpilation pattern treats includes, variables, and skill modules as a dependency graph with a golden rendered output. https://developers.googleblog.com/building-scalable-ai-agents-with-modular-prompt-transpilation/
  • Conductor's portable plugin keeps spec.md and plan.md in the repo while supporting conversational work across Gemini CLI, Antigravity, Claude, and other tools. https://developers.googleblog.com/evolving-spec-driven-development-conductor-now-supports-antigravity/
  • GitHub Copilot code review now reads instructions from the pull request's head branch, so instruction changes can be tested in the same change that proposes them. https://github.blog/changelog/2026-07-17-copilot-code-review-customization-and-configurability-improvements/

Code & Tools

  1. ADK Go 2.0 - compose typed graph nodes with fan-out/fan-in, durable human pauses, retries, concurrency caps, and one telemetry tree for agents and workflows. https://developers.googleblog.com/announcing-adk-go-20/
  2. Copilot review setup - add a repository-level copilot-code-review.yml, branch-tested instruction files, and an independent review firewall instead of sharing the cloud agent's runtime assumptions. https://github.blog/changelog/2026-07-17-copilot-code-review-customization-and-configurability-improvements/
  3. Vercel Plugin for Kimi Code - install platform skills on demand so the agent can pull current Next.js and Vercel guidance without bloating every session. https://vercel.com/changelog/vercel-plugin-now-available-in-kimi-code-cli
  4. Chat SDK Slack adapter - add agent badges, suggested prompts, streaming fallback, and native feedback buttons to the Slack surface. https://vercel.com/changelog/chat-sdk-adds-native-slack-agent-support
  5. Vercel Sandbox inbound transfer - package installs, Git clones, and dataset pulls no longer count toward Sandbox Data Transfer usage; outbound traffic and compute remain billable. https://vercel.com/changelog/data-downloaded-by-vercel-sandbox-is-now-free

Tech Impact

  • Prompt diffs become release diffs. If an instruction can change production behavior, it needs an owner, an eval, a review path, and a rollback story.
  • Repository artifacts beat chat memory. Portable specs and compiled prompts reduce tool lock-in, but stale shared instructions become cross-agent compatibility bugs.
  • Successful work is the metric. Retries, review time, failed tool calls, and human escalations belong beside token cost when teams score an agent workflow.
