# AI Operator Kit — START HERE

Welcome to the AI Operator Kit (v2).

This product gives you practical templates to run a cleaner weekly operating system across sales, delivery, and automation.

## What to open first (in order)

1. `deliverables/ai-operator-kit-sops.md`
   - Set your workflow foundations first.
2. `deliverables/ai-operator-kit-dashboard-template.md`
   - Define what you will track weekly and how decisions are made.
3. `deliverables/ai-operator-kit-prompts.md`
   - Use prompts to speed up execution of the SOPs.
4. `deliverables/ai-operator-kit-automation-checklist.md`
   - Automate only after your manual process is stable.

## 30-minute setup checklist

- [ ] Pick one offer/service to run through this system.
- [ ] Customize the SOP owners and escalation rules.
- [ ] Copy the dashboard template into your workspace (Notion/Sheets/Airtable).
- [ ] Save 5–10 prompts you will use weekly.
- [ ] Identify one workflow to automate this month.

## Recommended weekly cadence

- **Monday:** Confirm top 3 priorities from dashboard + pipeline.
- **Mid-week:** Check delivery blockers and client dependencies.
- **Friday:** Run weekly review, log decisions, and set next-week owners.
