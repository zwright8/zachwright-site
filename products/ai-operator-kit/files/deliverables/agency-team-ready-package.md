# AI Operator Kit — Agency Team-Ready Package

This package is designed for multi-operator teams running client delivery at consistent quality.

## Package components
1. Team operating model
2. Role ownership matrix
3. Cross-functional handoff contract
4. QA scorecards
5. Capacity planning template
6. Training curriculum

---

## 1) Team Operating Model
- Weekly cadence: Monday planning, Wednesday unblock, Friday review
- Escalation windows: P1 (<4h), P2 (<24h), P3 (<72h)
- Single source of truth: CRM + dashboard + task board

## 2) Ownership matrix (RACI-lite)
- Sales Ops: qualification, proposal follow-up
- Delivery Ops: onboarding, execution, QA
- Growth Ops: content/ad channels, attribution tags
- Finance Ops: reconciliation, margin tracking

## 3) Handoff contract
Every handoff must include:
- objective
- done criteria
- context links
- due date and owner
- escalation contact

## 4) QA standards
- Deliverable format check
- Scope compliance check
- Actionability check
- Client-readability check

## 5) Capacity planning
- Active clients per owner
- Cycle time per deliverable type
- Weekly throughput cap
- Buffer for urgent work

## 6) Team enablement
- onboarding sprint (week 1)
- shadow + supervised delivery (week 2)
- independent execution with audit (week 3)
