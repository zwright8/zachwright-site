# AI Operator Kit — Agency Implementation Playbook (30 Days)

## Week 1: Foundation
- Set roles/owners for Sales, Delivery, Growth, Finance
- Configure pipeline stages and required fields
- Select one service line as pilot

## Week 2: Pilot
- Run 3 live client workflows with full SOP adherence
- Measure response SLAs, quality pass rates, and handoff health
- Log all blockers and fixes

## Week 3: Standardize
- Publish final SOP revisions from pilot findings
- Train each owner on common failure modes
- Implement first automation set (lead capture, reminders, delivery triggers)

## Week 4: Scale
- Expand to additional client workflows
- Launch KPI dashboard cadence
- Enforce weekly quality governance review

## Exit criteria (Day 30)
- SOP adherence > 85%
- First-pass QA > 90%
- Handoff failure rate < 10%
- Weekly dashboard decisions logged consistently
