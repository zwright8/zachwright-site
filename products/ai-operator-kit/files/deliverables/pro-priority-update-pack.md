# AI Operator Kit — Pro Priority Update Pack

Use this pack when operating conditions change quickly and you need controlled updates.

## Included update modules
1. **Offer Positioning Refresh Template**
2. **Urgency Event Response Template**
3. **Channel Priority Rebalancing Template**
4. **Pricing Adjustment Decision Memo Template**
5. **Risk Escalation Update Template**

---

## 1) Offer Positioning Refresh Template
- Trigger: conversion decline > 20% for 2 weeks
- Inputs: latest objections, funnel leaks, competitor shifts
- Output: updated headline, value prop bullets, CTA framing

## 2) Urgency Event Response Template
- Trigger: sudden opportunity/risk event
- Output in 30 minutes:
  - what changed
  - impact on offer/channel
  - immediate 72-hour actions
  - owner assignments

## 3) Channel Priority Rebalancing Template
- Trigger: CAC proxy or engagement performance divergence
- Output:
  - reduce/increase channel allocation table
  - expected upside/risk
  - rollback threshold

## 4) Pricing Adjustment Decision Memo
- Trigger: strong conversion with delivery capacity constraints OR weak conversion with healthy quality
- Output:
  - current conversion + margin snapshot
  - proposed price test
  - success/fail criteria
  - rollback rule

## 5) Risk Escalation Update Template
- Trigger: repeated delivery misses, policy risk, quality incidents
- Output:
  - issue statement
  - customer impact
  - containment action
  - prevention action
  - next review date

---

## Usage cadence
- Review this pack weekly in Friday ops review.
- Execute only one major update test at a time.
- Keep changelog entries for every update and decision.
