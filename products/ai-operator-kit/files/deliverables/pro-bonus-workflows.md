# AI Operator Kit — Pro Bonus Workflows

These workflows are built for operators who already run the core kit and want higher output with fewer dropped handoffs.

## Workflow 1: Lead-to-Close Sprint (7-Day)

### Goal
Move a qualified lead from first contact to signed agreement in 7 days.

### Inputs
- ICP criteria
- Offer/tier pricing
- Discovery call script
- Proposal template

### Steps
1. Day 0: Qualify lead using ICP scorecard (fit, urgency, budget, authority).
2. Day 1: Run discovery call with decision-map questions.
3. Day 1 (same day): Send structured recap + proposal option set (good/better/best).
4. Day 3: Objection handling follow-up with one clear next action.
5. Day 5: Decision nudge + scope-lock reminder.
6. Day 7: Close-loop sequence (won/nurture/closed-lost with reasons).

### KPI targets
- Discovery-to-proposal SLA: < 24h
- Proposal response rate: > 60%
- Close rate on qualified leads: > 30%

## Workflow 2: Weekly Revenue Operating Cadence

### Goal
Run one consistent weekly cycle that improves pipeline and delivery quality.

### Monday (45 min)
- Set top 3 revenue priorities
- Assign owners and due dates
- Confirm key blockers

### Wednesday (20 min)
- Midweek checkpoint
- Escalate blocked tasks
- Update close probability by deal

### Friday (45 min)
- Score KPI results
- Review wins/losses
- Set experiments for next week

### KPI targets
- Priority completion rate: > 80%
- Blocker resolution time: < 48h
- Weekly conversion trend: non-negative

## Workflow 3: Content-to-Lead Machine (14-Day)

### Goal
Turn consistent content into qualified conversations.

### Steps
1. Pick one high-intent problem per week.
2. Publish 3 content assets (insight, proof, framework).
3. Attach one CTA path (DM keyword or form).
4. Route inbound responses into CRM stage + source tag.
5. Trigger follow-up sequence within 4 hours.
6. Review best-performing angle every Friday.

### KPI targets
- CTA response rate: > 2%
- Lead response SLA: < 4h
- Content-to-discovery ratio: > 10%

---

## Workflow 4: Delivery Quality Loop

### Goal
Increase client satisfaction and reduce rework.

### Steps
1. Pre-delivery QA check (scope, acceptance criteria, formatting).
2. Delivery message with clear next action.
3. 48-hour feedback follow-up.
4. Capture testimonial or issue in quality log.
5. Feed issues into SOP updates weekly.

### KPI targets
- First-pass acceptance: > 90%
- Rework rate: < 10%
- Testimonial request completion: > 70%
