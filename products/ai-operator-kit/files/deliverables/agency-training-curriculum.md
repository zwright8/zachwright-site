# AI Operator Kit — Agency Training Curriculum

## Module 1: Operating System Fundamentals
- Objective: understand cadence, SOPs, and KPI behavior
- Exercise: run one complete weekly cycle in sandbox

## Module 2: Sales-to-Delivery Handoff Excellence
- Objective: zero-context-loss handoffs
- Exercise: convert discovery notes into implementation-ready brief

## Module 3: Quality and Client Communication
- Objective: ship high-quality outputs consistently
- Exercise: QA scorecard on 3 sample deliverables

## Module 4: Controlled Automation
- Objective: deploy safe automations without creating operational debt
- Exercise: implement one Phase-1 automation with rollback plan

## Certification gate
- 2 supervised deliveries passing QA >= 9/10
- one complete dashboard review submitted
- one postmortem document completed
