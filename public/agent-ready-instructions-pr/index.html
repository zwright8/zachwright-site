The process

Evidence first. Scope second. Payment third.

  1. 01

    Run the free preflight

    Complete the browser-only preflight or automated public audit so the request begins with an immutable evidence baseline.

  2. 02

    Open a non-binding scope request

    Name the repository, full revision, selected tier and paths, public workflow, and your authority to receive the correction pack. Use the browser-local builder and review the generated business email before sending. Never include payment details, credentials, private files, personal or customer data, checkout links, or transaction IDs.

  3. 03

    Receive written scope

    WrightOps revalidates the repository and confirms the exact tier, paths, price, delivery clock, labor cap, exclusions, and acceptance shape in writing. Only then does WrightOps provide a private, buyer-specific PayPal Goods & Services checkout.

  4. 04

    Review the correction pack

    Work begins only after provider-confirmed settlement. WrightOps delivers replacement Markdown, a unified diff, evidence notes, and acceptance checks within one business day after settlement and complete accepted inputs.

Before you request scope

Direct answers.

Is a scope request a contract or payment obligation?

No. WrightOps must confirm the exact written scope before privately sharing checkout.

Which tier should I choose?

Choose $149 when one existing instruction file needs correction. Choose $249 when the repository needs root AGENTS.md plus either root CLAUDE.md or .github/copilot-instructions.md.

Does WrightOps run the repository's checks?

No. The service reads public evidence and may document supported commands, but it does not clone or execute target code.

Does WrightOps create a branch or pull request?

No. WrightOps currently has no authorized GitHub write surface for buyer repositories. Delivery is replacement Markdown plus a ready-to-apply unified diff. The buyer applies it or explicitly supplies a later authorized business write path.

What happens if WrightOps cannot deliver?

If WrightOps cannot deliver the confirmed scope, you receive a full refund of every dollar paid through the original payment rail.
