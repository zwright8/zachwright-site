Three-pass customization

              
Make the starter true before making it long.

              
Good instructions narrow uncertainty. They do not turn undocumented assumptions into policy.

            

            

              
01 / MAP
Resolve every path
Replace path placeholders only after confirming that each file or directory exists at the revision an agent will read.

              
02 / EVIDENCE
Copy established commands
Use committed scripts or project documentation as the source for setup and verification. Delete empty command sections.

              
03 / BOUND
Name the approval gates
State where an agent must stop for destructive, production, credentialed, irreversible, or paid actions.
